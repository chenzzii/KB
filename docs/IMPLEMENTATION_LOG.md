# v0.1 演武沙盒

## 本輪範圍

P0 資料導入及 P1 可玩戰鬥切片。採 Vite + TypeScript + 原生 DOM/CSS 作為介面，未使用 React/PixiJS：30 格棋盤不需額外渲染框架；所有規則與 UI 完全分離，可日後替換渲染器。
原始交接包的 36 個清單檔案保持 SHA-256 相符，研究基線、映射與生成兵表未被改寫。新增 `scripts/generate.mjs` 產生供瀏覽器使用的精簡資料，沒有複製來源引擎碼或遊戲素材。

## 檔案與架構

- `src/core/types.ts`：狀態、命令、事件型別。
- `src/core/engine.ts`：純函式 `applyCommand`；戰前招募、換位、合併拆分、戰鬥移動、攻擊、反擊、回合與勝敗。
- `src/core/rng.ts`：UTF-16 code unit 的 FNV-1a 32-bit 種子轉換、xorshift32 與固定取整順序，零狀態有非零 fallback。無 `Math.random()` 或時間依賴。
- `src/core/ai.ts`：確定性距離／HP／ID 排序及追近目標。AI 透過一般命令操作，所有動作皆被錄製。
- `src/core/replay.ts`：Session 命令日誌、排序 JSON、WebCrypto SHA-256，匯入重算每一事件與最終狀態。版本與資料雜湊不相符即拒絕；目前沒有舊格式遷移，示範格式 `0.1.0-example` 不當成有效回放。
- `src/content/load.ts`、`scripts/generate.mjs`：sourceTroopId 一對一導入，檢查全欄位與能力，精簡產物排除來源地圖／城市／敵將身份與素材路徑。
- `src/main.ts`、`src/style.css`：繁中介面、鍵盤／滑鼠操作、兵表、警告與重播。採原創印章、文字與幾何符號，沒有外部字型／圖片／音樂請求。
- `tests/engine.test.ts`：50 項規則、資料、邊界與重播測試。
- `scripts/browser-smoke.mjs`：真實瀏覽器整軍、招募、兵表、操作、整場模擬、回放與版面驗證。
- `.github/workflows/ci.yml`：資料驗證、測試、建置及 CLI 模擬；這份工作流程尚未在 GitHub Actions 遠端執行。

## 已完成功能

- 25 兵種全數可讀、可招募，14 法術／8 神器／4 職業／17 敵將名稱索引。
- 五隊戰前交換、滿血無狀態合併／拆分、兵數與 HP 守恆；交換包含殘血與狀態。合併取較少彈藥，拆分沿用彈藥，不補充。
- 逐隊 `count * hp` 統率顯示，等於統率不顯示超額。超額僅提示，沒有虛構失控懲罰。
- 6 欄（x=0..5）×5 列（y=0..4）；起始我方 x=0、敵方 x=5，依隊位決定 y。
- 正交 BFS 平地移動、兵團阻擋、近戰、遠射耗彈、反擊、殘血延續、死亡、勝敗、重開及簡易 AI。
- 固定種子、初始狀態、資料雜湊、規則版本、命令、全部事件與最終狀態 SHA-256 的 JSON 匯出／匯入。匯入不超過 10 MB／50,000 指令，拒絕未知指令、錯誤版本、初始狀態、事件或最終雜湊。

## 證據與暫行規則

- 來源兵種資料為 `source-extracted`，不是 DOS 已驗證。
- 近戰近似式參考交接包中的 OpenBounty 摘要：`max(1, floor(count * roll * (skill + 5 - defenderSkill) / 10))`，傷害限制於目標現有 HP。參考層級 `open-source-implementation`；尚未獨立釘選並核對上游源碼版本，不能宣稱精確復刻。
- 傷害下限、格數、起始位置、輪流整方行動、每隊一次攻擊、攻擊後不可移動、全場遠射、相鄰牽制、遠射套同一近似式及每輪一次反擊均為 **proposed-new-game** 暫行決策。
- 每輪由我方開始；再次輪到我方時雙方反擊次數重置。遠射不引發反擊，被擊殺者不反擊。
- 受傷以整隊總 HP 儲存，`count = ceil(totalHP / unitHP)`；不在回合切換時補滿。下次攻擊使用當前存活兵數。
- `fly / undead / absorb / regen / magic / leech / scythe / immune` 全部未實作，在 UI 明示；具有這些標籤的單位仍只能使用基本行動。
- 士氣矩陣、失控行為、薪資、法術與神器效果未啟用。OpenBounty 參考 JSON 雖含士氣矩陣，但本包證據登錄仍標未核實，因此未套用。
- 四項來源異常原封保留。特別是法術 6 解析欄位雖為 2000，仍不採其為權威價格，保留 `['250','2000']`。
- 新發現文件／資料衝突：`hero_mapping.json` 將 Sorceress 對應豪俠、Barbarian 對應方士，與文件相反，角色描述亦不一致。保持原檔並顯示第五項診斷，職業效果未啟用；後續需確認內容映射意圖。
