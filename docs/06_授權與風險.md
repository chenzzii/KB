# 來源、版權、技術風險

## 研究材料 vs 可發布成品

本包來自使用者上傳壓縮檔的**靜態解析成果**，不包含原遊戲 exe、ROM、原始美術、音樂及地圖 tile。研究資料的授權與原始商業素材的授權不同，不能因 openKB 能執行就假設原始遊戲素材可自由重散布。

- `data/free` 相關內容：此前檢查顯示整合包有 `data/free/COPYING`，註明 CC-BY-SA 4.0 / GPLv3 或更新版雙授權條款；使用或散布前請再核對完整原文、權利人及個別素材授權範圍。
- openKB / 繁中 fork 的引擎程式碼與本包提取的參數**不是同一種資產**；若複製 GPL 原始碼，應評估相應 GPL 義務。單純閱讀其行為並獨立設計 TypeScript 邏輯不等於可以直接拷貝原碼。
- OpenBounty 代碼儲存庫標示 MIT；若要 fork/沿用其程式必須保留對應許可及通知。原版 King's Bounty 的美術不因 MIT 引擎而變成 MIT。
- `data/reference` 的角色名、敵人、城址及文章仍是**研究用**資料；公開新作應使用 `data/content` 的原創設定，且應將參考資料從 production build 排除，避免直接發佈受保護的內容。

## 已知危險假設

1. `KB.EXE` 並非經過完整版本/檔案一致性驗證；不可說精確 DOS 遊戲已全數逆向。
2. `spoils` 不是已證明的週薪；`10s0` 不能默默視為 1000。
3. 法術 `超渡術` 原資料有兩個金價；必須查 parser 或做實際測試。
4. 士氣、反擊、RNG 次序、AI、神器效果及不死/吸血各技能都須程式核實。
5. 原作有 4×64×64 地圖、26 城堡/26 城鎮，不代表新作可以直接複製配置。
