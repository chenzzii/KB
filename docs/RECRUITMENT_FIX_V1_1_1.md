# v1.1.1 據點招募修正

使用者走到柳灣鄉營後找不到招兵方式。重現發現據點面板沒有招募按鈕，需另外切到「整軍」；原有招募又與整軍共用來源欄位及兵數，選到不同兵種或超過限制時不容易理解。原本從整軍招募鄉勇可以成功，這次修正的是入口、操作與回饋。

城鎮及有兵源的營地新增「招募部曲」，直接開啟該據點的招募面板。切換兵種會自動選擇同兵種隊伍或可用空欄；編入欄位、拆分兵數與整軍操作分開。輸入兵數時即時顯示費用、庫存與本欄可招人數，不替換輸入框或中斷打字。庫存耗盡、不同兵種、統率已滿、銀兩不足、無效兵數均顯示原因並停用招募按鈕；成功時就地顯示招募結果。

遊戲核心、兵種數字、地圖及規則版本均未改動，存檔 schema 1 維持相容。招募預覽只是介面提示，實際命令仍由原規則引擎驗證。
