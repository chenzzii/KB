# v1.4：角色大圖、精簡旅程標頭、系統選單、購買回饋

依使用者截圖標註修改，只改呈現與操作；規則、數值與存檔格式不變。

1. **選角畫面**：所選職業的肖像放大到 180px（手機 130px），職業卡片肖像 72px，標題與說明字級加大。
2. **旅程標頭**
   - 主角肖像與職業名稱移到右側狀態列（日程、步數、天候……之前），左側只留「烽火歸途」。
   - 「華夏改良 · 種子」不再顯示於標頭，改在系統選單上方以小字顯示。
   - 匯出／讀取／匯入存檔、標題畫面、新旅程設定、音效、配樂、音量、動作，全部收進「⚙ 系統」按鈕；點開後分為「存檔」「旅程」「聲音與畫面」三組，按「關閉」收起。
   - 舊自動化腳本（`jiuzhou-automation-skip-title`）會讓系統選單保持展開，以維持原有檢查。
3. **購買回饋**：購買符籙、招募部曲、租船、客棧休整、占領城關等花費銀兩的操作，會
   - 播放兩聲金幣「叮、噹」音效（`soundtrack.cue('coin')`，受音效開關控制）；
   - 從點擊處飛出 7 枚「兩」字金幣到右上的銀兩數字，並顯示「−N 兩」；
   - 銀兩數字閃金色放大，所購符籙卡片亮起金框。
   - 動作關閉或系統減少動態時，只保留音效與金額文字。
