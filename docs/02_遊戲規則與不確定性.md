# 遊戲規則清單與證據等級

## 核心原則

目前來源 ZIP 的 `data/free/*.ini` 已解析，但 DOS 1.00 真正程式行為**尚未完整逆向**。`KB.EXE` 有 DOS MZ 及 1990 文字，不能因此推出所有 openKB 行為與原版相同。

| 證據層級 | 意義 | 是否可聲稱 DOS 原版 |
|---|---|---|
| `source-extracted` | 直接從使用者繁中 ZIP 的 INI 等取得 | 否，僅有重製版模組資料 |
| `open-source-implementation` | 可於 openKB/OpenBounty 程式碼或規格定位 | 否，除非 DOS 實測一致 |
| `manual-documented` | 原版手冊明文記載 | 可說明有文獻，仍需驗證實際細節 |
| `dos-experiment-verified` | DOSBox 逐步實測、記錄版本＋輸入＋輸出 | 是，限定已測版本與情境 |
| `unverified` | 目前缺證據 | 不可 |
| `proposed-new-game` | 全新設計 | 不適用 |

## 可直接讀取的欄位（source-extracted）

- 25 兵種：HP、技能、速度、近戰上下限、遠射上下限與彈藥、招募價、A~E、部分特殊能力。
- 14 術：效果類型、效果參數與原資料價格字串。
- 8 神器：能力 key，但效果與其中部分 key 意義待驗證。
- 17 通緝犯：獎金與最多五隊部隊。城鎮、城堡、四層 64×64 地圖尺寸。
- 原版地圖與所有原圖不進正式新作，相關資料只供分析及對照。

## 要從引擎確認或做 DOS 實驗的規則

### 戰鬥
- 棋盤尺寸：研究版先用 6 列×5 行（座標及橫豎定義需一致），雙方最多各五兵團；待確認原版實作與起始位置。
- 攻擊流程：行動點 → 射程/鄰接/障礙 → 攻擊/反擊 → 隨機傷害 → 加成與減傷 → 擊殺／受傷殘量 → 特殊效果 → 士氣或回合效果。
- OpenBounty 已整理的普通攻擊近似公式：`floor(N * R * (attackerSkill + 5 - defenderSkill) / 10)`，士氣和神器可能再修正。**這不是目前已由 DOS 實證的公式，也不一定覆蓋遠射/吸血/魔法。**
- 受傷殘量 carry-over 要定義、測試；多單位受傷不是每回合都補滿。
- 特殊能力 `fly / undead / absorb / regen / magic / leech / scythe / immune` 一一列測試。名稱標籤不等於行為已實作。
- 敵人 AI：目標優先、移動策略、射擊/近戰選擇、反擊判斷需分開驗證。

### 統率與士氣
- 參考版的統率模型是**每一隊兵數×單兵 HP**對照英雄統率，而不是把全軍 HP 全部加總。邊界相等時與過額失控時機需驗證。
- A、B、C、D、E 只先保留出處，**陣營士氣配對矩陣尚未核實**；不能假裝「幽冥遇官軍必定低士氣」已經是原版機制。
- 新版可增加陣營劇情關係，但必須與原作研究模式解耦。

### 經濟及時間
- 原作參考有 40 地圖步／日、5 日／週、一般難度 600 日等；由另一份研究資料提供，應以具體版本比對。
- OpenBounty 參考的週薪模型：`count * floor(recruitCost/10)`。**`spoils` 未驗證，不能等同維持費。**
- 收入、週薪、城鎮補兵、賞金、招募、英雄階級/統率成長結算順序應有細部事件日誌。
- 欠餉是否離隊：原版說明書與重製實作可能不同。請保留可切換規則，未驗證時不要在 UI 說「原版就是如此」。

## 第一輪資料異常（不可跳過）

1. `troop7.file` 缺失：檢查圖片 loader fallback；新作改用原創素材、不依賴此欄。
2. `troop14.spoils = '10s0'`：不是整數。源值保留，不能逕改成 100 或 1000。
3. `troop17.file = 'troll.png'`、檔案實際可能是 `trol.png`：需查路徑與 fallback。
4. `spell6.gold` 重複值 250 和 2000：未確認 INI parser 優先順序；不得自行擇一並聲稱原版價格。

## DOS 對照實驗紀錄格式

每次記錄 `gameVersion`, `executableSha256`, `ruleset`, `seedIfKnown`, `initialState`, `commandSequence`, `expected`, `observed`, `screenshotOrLog`, `evidenceStatus`, `notes`。

先做簡單樣本：100 統率 + 10 弓箭手（HP10）與 11 弓箭手；同種部隊相等/超額；近戰極值；遠程 0 彈藥；擊殺一個單位與殘血剩餘；士氣 A+B+A+E；每週維持費遇資金不足；特殊能力各一例。
