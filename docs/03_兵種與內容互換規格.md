- `fly` = 飛行，紙鶴靈／御風方士／血魅／鬼將／蛟龍；

- `absorb` = 汲取，幽魂；`regen` = 再生，樹魁；`magic` = 施法，祝由巫醫／御風方士；

這些中文描述是功能標籤，不代表觸發、數值、冷卻已知；必須從引擎 source 建 test vector。

## 隊伍互換 UI 規格

- 五槽 `armySlots: [Stack|null, ...]`。每隊包含 `instanceId`, `unitId`, `count`, `woundedHpOrCarry`, `statusEffects`，非必要狀態不得在交換時消失。
- `swap(slotA,slotB)`：只是交換整個 stack，包括傷害與狀態。
- `merge(slotA,slotB)`：只有相同 `unitId` 且相容狀態才允許；剩餘血量與狀態不能簡單清零，合併策略需寫清楚。
- `split(slot,count)`：若有空欄且 `0<count<source.count` 才允許；受傷狀態按可明確驗證的規則分配；第一輪可限制戰鬥外「全部滿血才能拆分」。
- **不能把「換位」做成無代價的兵種轉換**：農夫不能直接交換成蛟龍。真正的兵種轉換屬招募／升階系統，若要加入，須明訂資源成本及新作規則。
- `recruit(unitId, count)`：資金是否足夠、據點是否有供應、部隊欄是否有空位/同型可併、統率是否超額，各項分開檢核。
