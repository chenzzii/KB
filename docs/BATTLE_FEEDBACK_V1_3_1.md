# v1.3.1：遠射自動判斷與戰果報告

使用者回報：「目前沒辦法進行遠程攻擊，擊敗敵軍之後沒有收益報告」。

## 原因

- 引擎一直支援遠射，但介面點敵軍時固定使用「兵團動作」下拉選單，預設是近戰；弓手點遠處敵軍只會得到「近戰須正交相鄰」錯誤。
- 勝利時引擎會給討伐憑證、統率 +100、可能的山印／木印與法力，但介面直接回地圖，沒有任何摘要；賞金要回城鎮領取，也沒有說明。

## 修正（只改介面，規則與存檔格式不變）

- 「兵團動作」新增並預設為「自動」：相鄰就近戰；不相鄰時，有彈藥且沒被貼身就遠射，否則用兵種魔法。手動選近戰／遠射／魔法仍可用。
- 選取兵團後，可攻擊的敵軍加框：紅框近戰、橘框遠射、紫框魔法。指令面板顯示「可遠射：直接點任何敵軍（剩 N 發）」或不能遠射的原因。
- 無法攻擊時顯示具體原因（沒有遠射能力、彈藥用盡、被相鄰敵軍牽制、已行動）。
- 勝利後跳出戰果報告：討伐憑證與可領賞金、統率變化、取得的印、法力變化、經過日數、我方各部曲出戰／存活／損失、殲滅敵軍數、待領賞金總額。
- 撤退後顯示撤退報告；在城鎮領賞時顯示每筆賞金、合計與銀兩變化。
- 賞金公式抽出為 `bountyReward()`（`src/campaign/engine.ts`），數值與原本相同，介面報告與引擎共用。
- 戰鬥首次提示改為說明遠射與目標框。

## 測試

`npm run test:battle-report`（11 項）：預設自動、弓手提示、遠處敵軍標記、直接點擊即遠射、近戰兵團的錯誤說明、勝利報告內容、關閉報告、城鎮領賞報告與銀兩更新。舊瀏覽器腳本（設定 `jiuzhou-automation-skip-title`）不顯示報告視窗，以免阻擋既有流程。

## v1.3.2：斷雁寨「點了沒反應」

使用者回報在斷雁寨點選後沒有反應。原因：尚未在青禾府接受山河三印委託時，討伐／招安／交易按鈕仍可點，引擎回傳「請先接委託」的錯誤，但錯誤只顯示在頁面頂端，玩家捲動到地圖時看不到。

- 斷雁寨、聽雨古廟、天衡烽臺在未接委託（或烽臺三印未齊）時，相關按鈕改為停用，並在地點面板顯示原因與「前往青禾府」按鈕。
- 所有錯誤訊息另外以浮動提示顯示在畫面下方 5 秒，不論捲動到哪裡都看得到。
- 「討伐」按鈕標明「立即開戰」；斷雁寨首次提示補充需先接委託。
- `test:battle-report` 增加 3 項檢查（共 14 項）。規則與存檔格式不變。
