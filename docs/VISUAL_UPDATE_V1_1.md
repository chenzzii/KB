# v1.1 美術呈現更新

v1.0 的線條圖示與純色棋盤屬於原型視覺，先前稱為完整美術不夠精確。此版針對實際遊戲畫面補入繪製風格資產。

- 25 種全身兵種、4 英雄與 17 敵將肖像。
- 繪製戰場背景、4 類障礙物、4 個城鎮／結局場景。
- 8 種地形、6 類建築、14 符籙及 8 神器。
- 位移、射擊軌跡、攻擊／受擊、HP 數字與死亡消散，支援減少動態效果。
- 手機版重新排版；地圖單格顯示由 24 改為 40 像素，世界仍是 32×32，座標及遊戲規則沒有改動。

圖片由 OpenAI image_gen 生成，遊戲直接使用原始 PNG 圖集。靜態角色搭配介面動效，尚未製作逐格行走／攻擊動畫；場景會共用插畫。五張 PNG 共約 16.8 MB，首次開啟需載入。這不代表商業發售級的美術精修與效能優化均已完成。

## 驗證

114 項測試與正式建置通過。兩模式 × 三路線的正常通關重播雜湊與 v1.0 相同，舊冒險存檔仍可驗證載入。原交接包 37 檔逐位元不變。

正式建置以 GitHub Pages 的 /KB/ 子路徑執行 Chromium：實際地圖點擊／尋路、招募、戰鬥、領賞、存檔、六段結局重播、破損存檔拒絕、圖鑑、手機版均通過；新增美術檢查確認全部五張 PNG 實際解碼、角色位移、射擊軌跡與 HP 回饋，沒有 pageerror 或缺失資產。公開網站部署狀態仍以 GitHub Pages 顯示為準。
