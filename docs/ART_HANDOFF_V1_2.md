## 圖集選取與資料對應

ATLAS_INDEX 內的 index / row / column 全是零基。CSS background-size 與 background-position 直接對應現有遊戲。圖像寬高不一定可被格數整除；pixelBoundsFloat 保留浮點界線供參考，沒有偷偷取整重裁原圖。若需改為獨立圖片，應由接手者另行規劃一致的匯出方式與對應驗證。

sourceTroopId 必須保持 0–24 一對一，不可因重新命名或排序而對錯人物。`references/` 附原始兵種、人物、符籙、神器與派系描述作設計參考；它們是原有規格資料，不是這次要求自動重畫的指令。

場景在遊戲會共用；四幅場景是肖像圖集末列的方形圖格，現有程式以保留比例的容器裁成橫幅。不要把整張 5×5 圖集當作單一人物或直接拉伸場景。

## 分層動畫整合

`integration/src/art/painted.ts`、`motion.ts`、`motion.css`、`painted.css` 是 v1.2 現用程式。`gallery.ts` 是遊戲圖鑑，依賴專案其他資料模組；這個美術包本身不是完整可執行遊戲專案。

角色用 CSS 剪裁身體、腿部／翼部，搭配待機、呼吸、浮空、伏身、踏步、揮擊及施法等程序動作。外層管理敵軍鏡像與整體移動，內層管理身體與肢體，避免 transform 互相覆蓋。相位依畫面時間更新，普通重繪不讓全軍一起重來；定身暫停、減少動態效果及手動關閉均有處理。

近戰、射擊、施法等指令觸發接入位於完整專案 `src/adventure.ts`，不是只貼 CSS 就會產生遊戲行為。若從完整專案接手，先保留原事件流程與存檔驗證，勿把美術或動作改寫到純規則引擎。

`integration/scripts/create-art.mjs` 只產生舊原型 SVG，不會重生這五張 PNG。不能拿它輸出取代使用者認可的新美術。

## 視覺方向與限制

現有畫面採華夏奇幻、竹林古庭、石階與古建築，角色以繪製風格呈現。介面主色可參考現有 CSS：深青綠 `#1d342c` / `#142921`、文字 `#eddfb8`、邊框金色 `#a58c54`、友軍血條 `#91bf87`、敵軍血條 `#d49b74`。這些是現有實作取樣，不是重新核定的品牌規格。

世界仍為 32×32、戰場 6×5。screenshots/world-atlas.svg 是現有原創世界配置，不能稱為原版四層 64×64 的還原。未提供來源遊戲原圖做逐像素比對。

本次包不含音樂素材，聲音／樂譜在完整程式包的 `src/audio/`；音樂說明附在 references/MOTION_MUSIC_V1_2.md 作上下文，不代表本包包含音樂工程。

## 驗證與預覽

直接開啟 preview.html 可看所有 91 項新版圖格／背景及原型 SVG，無外部依賴。原圖使用 CSS 圖格選取，不產生新的修改版 PNG。包內含逐檔 SHA-256 與 VERIFY_PACKAGE.py。實際預覽已經通過五張原圖解碼、91 項圖格／背景、86 SVG、25 兵種動作、動作開關、減少動態效果與手機無溢出檢查，沒有資源載入失敗或 JavaScript 錯誤。證據在 verification/。驗證以本機 HTTP 靜態服務執行；本次受管理瀏覽器封鎖 file 網址，因此未宣稱在此環境驗證過雙擊開檔。若本機限制直接開檔，可在解壓目錄執行 `python -m http.server 8080` 後開啟 `http://localhost:8080/preview.html`。

需要完整原始碼、存檔與遊戲成品時，請另用 jiuzhou-claude-handoff-v1.2.zip；輕量上下文包未附 PNG，可搭配本美術包補足圖片。
