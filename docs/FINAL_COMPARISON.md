# 烽火歸途 v1.0：與原設定／原有遊戲的完整差異盤點

## 比對基準與結論範圍

這份盤點在冒險通關驗證完成後整理。基準分三層：

1. 使用者上傳的開發交接 ZIP：規格及研究資料是此次能逐位元比對的原始依據。37 個檔案（含 SHA-256 清單）與目前儲存庫逐檔一致；沒有改寫其中的基線、內容映射或異常記錄。
2. 包內繁中 openKB free 模組及 OpenBounty 研究參數：可比較數值與結構，不能直接稱為 DOS 原版執行結果。
3. DOS《King's Bounty／御封戰將》實際行為及原始畫面：這次並未提供原始執行檔、完整地圖 tile、畫面或音樂。本報告不能宣稱已完成逐格、逐像素、逐音軌或二進位行為對照；此類差異明列為未核實。

因此，**資料原封不動，不代表玩法原封不動**。本作是交接包所設定的原創華夏遊戲，並非 DOS 移植；以下逐項記錄保留、變更、新增及無法核實項目。

## 三、兵種與英雄

- **保留不變**：25 個 sourceTroopId、HP、技能、移動、近戰／實體遠射區間、來源彈藥、招募價、能力 key、A–E 組別及全部異常字串。
- **名稱／敘事**：使用開發包的原創兵名、陣營與人物，不是原遊戲的角色；演武可切換來源名稱，冒險固定顯示新作名稱。
- **職業衝突**：原 hero_mapping.json 將豪俠／方士與 Sorceress／Barbarian 反向綁定。原檔未改；戰役另外依文字規格綁定 Knight→武將、Paladin→儒將、Barbarian→豪俠、Sorceress→方士。豪俠最低有效法力採 1，未照搬來源 0，也未限制只有來源 starts_with_magic 職業可施法；屬新作設定。
- **成長**：每解決敵將統率 +100、每三名增加一點法力，非已核實原版升階曲線。
- **隊位**：仍最多五隊；交換保留殘血與狀態，滿血才能合併／拆分。招募與隊位交換分開，沒有免費兵種轉換。
- **統率**：逐隊 count×HP，不以全軍加總。戰役招募會擋住超額；合併後超額不導入未驗證的失控 AI。這與完整原版失控系統不同。

## 五、十四法術與八件神器

- 七種戰鬥法術全部可用。火／雷／渡厄基值 25／10／50 參考來源，乘本作法力與法璧；不等於原版完整施法運算。
- 複製為 10×法力名兵，新增兵加入回復上限；來源的「10」未經 DOS 公式實驗。
- 還魂在研究模式回復單兵 HP×法力，華夏為 100×法力 HP；全滅須原格空置，復活後等下次行動才能動作，均為本作邊界決策。
- 定身到目標方下次行動結束；縮地只落空格、保留行動／狀態。
- 每方每次行動一道、初始每術兩張、個別攜帶上限，均為新作資源配置；職業初始法術容量未一比一採用來源。
- 冒險七術：架一格橋、40 次移動停時、揭露敵將、返回固定已訪城／鄉、召 10 鄉勇、統率 +50。不是原版完整傳送／時間／召兵公式。
- 原 spell6 的 250／2000 價格衝突保持；本作停止販售，初始符可使用，沒有選定一個權威價格。
- 八神器皆有來源／效果說明。劍 +50% 傷害、甲整數減傷、虎符雙統率、法璧雙法力、秘籙雙容量、令牌降船費；效果是研究參考。
- 金券 +50% 俸祿、俠義佩環招安七五折是新作設定；佩環在研究模式不啟用未知效果。

## 六、經濟、敵軍、任務與結局

- 每日 40 步、每週 5 日取自研究摘要；本戰役時限 180 日，不採來源普通難度 600 日，亦沒有四種原作難度。
- 週薪為 count×floor(招募價/10)，不使用 spoils；收俸後扣薪與船費。原版結算／欠餉差異尚未驗證；華夏欠餉減員一成、研究僅警告。
- 據點每週每兵種補 20、庫存上限 100，是獨立新作供應規則。
- 敵將身份取原創映射；戰役敵兵為來源數量除 25 向上取整、至少一人；賞金為來源除 5、至少 500。並未更動來源 CSV／JSON，但**實際遭遇難度與獎金明顯改變**。
- 招安／交易付費取印、占城 +500 俸祿、派系好感、敵對妖靈拒招均屬新作。原版是否存在相同外交系統沒有主張。
- 「山河三印」與三結局完全原創；收集三印取代原遊戲的完整故事／尋寶目標。可以武力終戰，也可盟約／贖金避免終戰。
- 撤退扣兩成存活兵與兩日，回青禾府；城內休整只回復存活兵傷勢。原版撤退／傷兵細節未逐項核實。

## 七、軟體、資料與相容性

- Vite／TypeScript／Vitest 沿用；原生 DOM/SVG 取代 React/Pixi，屬原規格允許的替換。沒有後端、登入、遠端 API 或來源遊戲二進位。
- 原始研究資料及新作映射均未改；新增平衡獨立放 `data/balance/chinese_campaign_v1.json`。規則與 UI 分離，但部分公式仍在 TypeScript，並非一切規則都能純 JSON 編輯。
- 冒險存檔記錄全旅程命令、快照、資料 SHA-256；匯入逐步重算。localStorage 自動存檔是新作功能。
- 冒險 schema 1，舊演武 schema 2 分開。更早的 v0.1 演武沒有遷移器，會拒絕；這仍是相容性限制，不能稱作原需求已完整解決。
- CI 已設定，實際驗證在本機 Linux／Chromium；Windows 11 與原 DOS 未實機驗證。沒有部署、推送或發布。

## 驗證可證明與不能證明的事

113 項測試、六個完整通關及完整重播、瀏覽器實際操作、圖像資產檢查，可證明本作這些路徑能執行且具決定性。萬場沙盒模擬只對該組預設場景提供穩定性證據，不能證明本作對原遊戲的忠實度、所有策略的平衡或無任何缺陷。

若要再做嚴格的原作復刻稽核，需要合法可用的特定 DOS 版本、可重現輸入／輸出與實際畫面／地圖作證據。這次沒有虛構該層驗證，也沒有為取得它而複製、執行或散布未提供的來源資產。
