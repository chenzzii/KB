## 實際驗證

- `npm test`：113 項通過。
- `npm run build`：TypeScript 與 Vite 靜態建置通過。
- `npm run validate:data`：通過，四項來源預期警告保留。
- `npm run campaign:verify`：研究／華夏兩模式，各自討伐、招安、交易三條路線，共六段正常通關及全指令重播。
- 討伐驗證在第 122 日完成；招安／交易第 7 日完成。通關指令包含真實行路、招募、法術、戰鬥、領賞及最終操作，沒有改寫狀態直接指定勝利。
- Chromium 冒險測試：實際行路／招募／戰鬥／領賞、十四符籙列表、十七懸賞、八神器、本機及檔案存讀、六段完整旅程重播與結局、破損檔拒絕、職業／模式及小螢幕。
- 既有演武測試仍保留，可另跑 `npm run test:browser`。
