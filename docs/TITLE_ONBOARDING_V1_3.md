# v1.3：標題畫面、選角與新手提示

只改呈現與操作；未修改規則引擎、地圖、數值或存檔格式（冒險仍為 schema 1／`campaign-1.0.0`，舊存檔可直接讀取）。

## 新流程

1. **標題畫面**：開始新旅程／繼續旅程（有本機自動存檔時才出現）／遊戲說明／設定。
2. **序章故事**：五頁原創敘述，可「下一頁」「上一頁」或「跳過故事」；設定中可勾選「略過開場故事」。
3. **選擇身分**：四職業卡片，顯示統率、起始銀兩、每週俸祿（收入）、法力、三項特色、難度與起始部曲；進階設定可選規則模式與亂數種子。
4. **聲音與畫面設定**：配樂開關與音量、音效、部隊動作、首次提示、略過故事、重設提示。保存於 `jiuzhou-settings`。
5. 進入遊戲後，旅程工具列有「標題畫面」可返回。

## 首次提示

`src/tips.ts`。第一次遇到下列情境時跳出說明，看過即記錄於 `jiuzhou-tips-seen`，不再重複：山河圖、青禾府、城鎮、營地、斷雁寨、敵將據點、古廟、烽臺、神器、戰鬥、整軍、招募面板、符籙、任務與行囊、終章。提示框可勾選「之後不再顯示任何提示」，設定頁可重設。

## 地圖區分

- 綠色方框＋「募」：可招募部曲的城鎮與營地。
- 紅色圓框（敵將肖像、脈動）＋「戰」：會發生戰鬥的敵將據點與烽臺。
- 橘色虛線＋「擇」：斷雁寨，尚未決定討伐／招安／交易。
- 紫色「廟」：事件地點；灰色「✓」：已平定。
- 地圖下方有圖例；地點面板與「行旅指南」的地點按鈕也有相同顏色標籤。
