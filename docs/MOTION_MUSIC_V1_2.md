# v1.2 軍隊動作與地圖／戰鬥配樂

## 軍隊動作

25 種兵種均接入持續待機動作。兵種使用各自的節奏與相位，分為呼吸備戰、伏身、重心轉移、蹣跚、骨架顫動、浮空、振翼、樹身搖動等動作家族。相位跟隨畫面時間，普通介面重繪不會讓所有角色一起從第一幀重來。

保留現有繪製圖集，以 CSS 剪裁分層及關節式變形呈現身體、腿部或翼部動作；這是程序式 2D 動畫，沒有另外重繪逐格 sprite。行走會踏步，飛行會前傾，近戰朝目標突進並揮擊、帶有刀光，遠射有拉弓／後座，施法有浮起及光暈；動作結束後恢復待機。定身單位暫停待機。

提供「動作 開／關」，並遵循系統的減少動態效果設定；網頁隱藏時暫停持續動畫。

## 新作配樂

| 情境 | 曲名 | 速度／長度 | 編曲 |
|---|---|---|---|
| 地圖探索 | 青嵐遠行 | 80 BPM、32 小節、96 秒循環 | D 大調五聲取向，笛聲主旋律、撥弦分解、弦樂和聲、低音、鐘聲及輕打擊；前奏、回答句、高音變奏與回歸 |
| 戰鬥 | 烽鼓破陣 | 116 BPM、32 小節、約 66.2 秒循環 | D 小調五聲取向，銅管式主旋律、弦樂、撥弦節奏、低音、戰鼓與沙鈴；切分節奏、增強段落與鼓花 |

兩首均為本作新編的原創樂譜，由 Web Audio 多聲部合成演奏，含立體聲、混響及動態壓縮；樂器名稱描述合成音色，並非真人樂器錄音。舊 `original_music.json` 保留作歷程，遊戲改採 `src/audio/score.ts` 的新樂譜。無外部音訊服務或下載依賴。

玩家按「配樂 開」後播放；進入戰鬥或撤退返回地圖會淡出舊曲、淡入新曲。走格、選兵或普通重繪不會重啟樂曲。音量可獨立調整並保存在本機，配樂及音效分別開關；切離冒險頁籤或隱藏網頁會停止排程。音效亦依行走、攻擊、遠射、施法及勝敗區分。

## 驗證

- 116 項單元／戰役測試、TypeScript 與正式建置通過。
- 正式建置 /KB/ 子路徑：25 兵種的實際分層姿態均隨時間改變；行走、近戰突進／刀光、射擊、定身暫停、手動關閉動作、減少動態效果、存檔重算與 390 像素手機版檢查通過。
- 同一瀏覽器中的真實 AudioContext 驗證：地圖 → 戰鬥 → 地圖自動換曲，切頁後返回仍只有一個音訊 context，音量設定不因重繪遺失。
- 以與正式遊戲相同的音色程式，離線渲染每首前 16 小節為聆聽 WAV：地圖 50 秒（含尾音）、峰值約 0.395、RMS 0.060；戰鬥約 35.1 秒、峰值約 0.493、RMS 0.066。兩段均有音訊且未削波；沒有以波形檢查冒充人工試聽或音樂品質評價。
- 原完整冒險瀏覽器與美術瀏覽器驗證通過：探索、招募、實戰、存檔、六段結局重播、圖集解碼及手機版。沒有 pageerror 或缺失美術。
- 遊戲核心、兵種數值、地圖、任務及存檔規則版本均未改動；原始交接包 37 個檔案逐位元保留。

## 檔案與執行

- 動作設定／圖層：`src/art/motion.ts`、`motion.css`、`painted.ts`。
